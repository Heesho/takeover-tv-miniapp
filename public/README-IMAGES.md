# Required Images for TakeoverTV

This directory should contain the following images:

## 1. logo.png
- **Size**: 200x200 pixels
- **Format**: PNG
- **Purpose**: App icon shown in splash screen and app store
- **Design**: Simple, recognizable icon representing TakeoverTV (e.g., TV with signal bars)
- **Background**: Can be transparent or match splash color (#000000)

## 2. og-image.png
- **Size**: 1200x630 pixels (3:2 aspect ratio)
- **Format**: PNG or JPG
- **Purpose**: Social sharing preview when app is shared in feeds
- **Design**: Eye-catching image with app name and tagline
- **Recommendations**:
  - Include "TakeoverTV" text
  - Add tagline like "Community-Controlled Television"
  - Use bold, high-contrast colors
  - Keep important elements in center (safe area)

## 3. screenshot1.png
- **Size**: Mobile dimensions (e.g., 390x844 for iPhone 14)
- **Format**: PNG
- **Purpose**: App screenshot for app store listing
- **Content**: Show the app in action with:
  - Video player with content
  - Channel info visible
  - Takeover button prominent
  - Professional looking state

## Creating These Images

### Using Figma/Design Tools
1. Create artboards with exact dimensions
2. Design your assets
3. Export as PNG with appropriate settings

### Using Placeholder Services (Temporary)
```bash
# You can use these URLs temporarily:
# logo.png: https://via.placeholder.com/200x200/000000/FFFFFF?text=TV
# og-image.png: https://via.placeholder.com/1200x630/000000/FFFFFF?text=TakeoverTV
```

### Using AI Image Generators
Prompts to try:
- **Logo**: "Minimalist TV icon, retro television with antenna, black background, white lines, 200x200"
- **OG Image**: "Social media banner for TakeoverTV app, community television, retro TV aesthetic, 1200x630"

### DIY with Code
See the example SVG in this directory for a simple programmatic logo.

## Tips

- **Keep it simple**: Simpler designs scale better and are more recognizable
- **Test at small sizes**: Your logo will be shown at various sizes
- **High contrast**: Ensure text/icons are readable against backgrounds
- **Brand consistency**: Use consistent colors and style across all images
- **Professional quality**: These represent your app in the Farcaster ecosystem
